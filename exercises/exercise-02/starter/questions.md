# Three questions for a fresh agent session

Ask them one at a time, in a new session started at the root of the repository.
For each one, note whether the answer is right and how many files the agent opened
or commands it ran before answering.

1. Which commands build and test the Catalog module alone?
2. May the ShoppingCart module import Account, and where is that decided?
3. What must be true before a change to ShoppingCart counts as done?

The expected answers are at the end of the lesson. Read them after you have noted the agent's.
